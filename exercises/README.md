# Equipment API exercises

Work through these guided exercises in order:

1. [Persistence, SQL, ORM and migrations](exercise-1.md)
2. [CRUD API](exercise-2.md)
3. [Local dictionary caching](exercise-3.md)

Begin with Exercise 1 for the setup instructions and starting-state check. Use
Python 3.11 or 3.12 and install the pinned dependencies from
`requirements-lock.txt`. The homework activity is separate; find it from the
[repository guide](../README.md).
